# 听我说，助记词，安全事，别大意

不是荐币，不是晒单，就聊一个东西：助记词。  
私钥也同理。  
记住一句话：谁拿到助记词，谁就是钱包的主人。  
你手里的币，只是别人待取的快递而已。  
下面全是干货，按小节来，别划走。  

> 风险提示：本文仅为安全知识分享，不构成任何投资建议。  

## 为什么绝不能截图 / 存网盘 / 发给任何人  

先问你一个问题：你手机里的截图，安全吗？  
不安全。  
相册会同步，云盘会备份，App会读取，黑客会偷。  
你截一张助记词，等于把钥匙拍下来，贴在门口。  

**截图？不行。**  
手机丢了，别人打开相册，钱包没了。  
手机中毒，恶意软件扫描相册，钱包没了。  
用屏幕共享软件，远程看你屏幕，钱包没了。  
甚至某些App，申请相册权限，偷偷上传图片，钱包又没了。  

**网盘？更不行。**  
网盘不是保险箱，是公共储物柜。  
员工能看到，黑客能攻破，漏洞能泄露。  
而且助记词是文字，网盘自带OCR识别，自动提取关键词。  
你存一份，等于免费帮黑客整理钱包清单。  

**发给任何人？最不行。**  
客服？不会要。  
官方？不会要。  
朋友？账号被盗怎么办？  
假客服、假官方、假“技术员”，全是骗子。  
他们套路都一样：先吓你，再哄你，最后让你交出助记词。  

具体步骤，记住这个：  
1. 有人让你“验证助记词” → 拉黑。  
2. 有人让你“截图保存” → 拉黑。  
3. 有人让你“发到邮箱” → 拉黑。  
4. 有人让你“私聊发我” → 拉黑。  

没有例外。  
没有例外。  
没有例外。  

## 离线保存法  

那正确做法是什么？  
离线！离线！离线！  
助记词只出现在一个地方：纸上。  
或者金属板上。  
总之，不碰电子设备。  

**方法一：纸笔抄写。**  
拿一张白纸，拿一支笔。  
断网，关手机，关电脑。  
在干净的环境里，一个一个单词抄。  
抄两遍，核对一遍。  
然后，把纸藏起来。  

藏哪？  
别藏枕头底下，别藏抽屉里。  
用密封袋装好，防潮防水。  
放保险箱，放银行保险柜。  
或者分散放，两张纸，两个地方。  
别告诉任何人位置。  

**方法二：金属助记词板。**  
纸会烧，会湿，会烂。  
金属板不会。  
买那种纯钢的，自带字母打码的。  
自己动手，一个一个敲上去。  
注意：别买带蓝牙的，别买带USB的，别买电子显示的。  
那些都是花架子，反而增加风险。  

**方法三：硬件钱包 + 纸备份。**  
硬件钱包本身是安全的，但助记词备份还是用纸。  
别把助记词存在硬件钱包里，那是没用的。  
硬件钱包只是签名工具，助记词才是根本。  

具体步骤，照做：  
1. 断网，关手机。  
2. 拿出纸笔，或金属板。  
3. 抄写/打码，核对两遍。  
4. 密封保存，分开放置。  
5. 不要拍照，不要录视频，不要发给自己。  

## 钓鱼套路揭秘  

骗子比你想象中努力。  
他们天天研究新话术，专门收割新手。  
我给你拆穿几个最常见的。  

**套路一：假网站。**  
你收到一条私信：“你的钱包需要升级，点链接。”  
点进去，网站长得一模一样。  
你输入助记词，钱包瞬间被搬空。  
记住：真正的官方，永远不会让你在网页上输入助记词。  
任何链接，先看域名，字母替换别中招。  

**套路二：假客服。**  
私信你：“我是XX钱包客服，你的账户异常，需要验证助记词。”  
你一想，客服应该靠谱吧？  
错。客服不会要你的助记词。  
助记词是唯一凭证，客服没有权限看。  
遇到这种，直接举报。  

**套路三：假空投。**  
“恭喜你获得XX代币，快去领取。”  
让你连接钱包，然后让你“授权”。  
你点了授权，骗子就能转走你所有资产。  
记住：天下没有免费的空投。  
真有空投，也不会有“授权助记词”这个步骤。  

**套路四：假软件。**  
你在网上搜“XX钱包下载”。  
第一个结果，是盗版。  
你下载，打开，输入助记词。  
钱包里的钱，就像进了别人的口袋。  
解决办法：只从官网下载，只从官方应用商店下载。  
最好用硬件钱包，彻底避开假软件。  

**套路五：假朋友。**  
“哥们，你上次说的那个币，我忘了助记词，你发我看看。”  
你一想，朋友嘛，没事。  
但朋友账号可能被盗了，或者朋友自己都不靠谱。  
记住：助记词，亲爹亲妈都不给。  
给了，就是你的钱包没了。  

所有套路的核心就一句话：  
**诱导你交出助记词或私钥。**  
你只要守住底线，谁也骗不了你。  

## 万事买不到的安全态度  

最后聊点心态。  
技术是死的，人是活的。  
再贵的硬件钱包，也防不住你自己作死。  

**第一，别炫耀。**  
你赚了多少，你钱包多大，别晒。  
晒了，就会有人盯上你。  
闷声发大财，才是真理。  

**第二，别图方便。**  
复制粘贴私钥？方便。  
但方便的结果，是泄露。  
微信收藏夹？方便。  
但方便的结果，是封号加丢币。  
安全从来不方便，方便从来不安全。  

**第三，别乱签名。**  
很多骗局，不偷助记词，而是骗你签名。  
一个陌生链接，让你签名“授权”。  
你签了，别人就能动你的资产。  
不认识的合约，不签。  
看不懂的交易，不签。  
宁可错过，不要过错。  

**第四，冷热分离。**  
大额资产，放冷钱包（离线设备）。  
小额资产，放热钱包（手机/电脑），用来日常交易。  
就算热钱包被盗，损失也就一点。  
别把全部身家放在一个热钱包里。  

**第五，定期检查。**  
钱包授权，定期清理。  
不用的DApp，撤销授权。  
看看有没有异常交易，有没有奇怪的签名请求。  
安全不是一次性的，是持续的习惯。  

**最后，记住一句话：**  
你的助记词，是你和财富之间唯一的桥。  
桥断了，谁也过不去。  
别截图，别网盘，别发人。  
离线存，分散藏，不炫耀。  
万事买不到的安全态度，就是：  
**永远怀疑，永远谨慎，永远把助记词当命。**

> 保护好自己的钱包，比赚钱更重要。  
> 朋友，别踩坑。祝你平安。
